Iglesia Pegaso — Simulador 3D con Ayuda IA Qué incluye index.html: simulador 3D existente con controles y ayuda que intenta conectarse a /api/ai. server.js: servidor backend que mantiene la clave de API fuera del navegador. package.json: dependencias y comando de inicio. Ejecutar localmente Instala Node.js 20 o superior. En esta carpeta ejecuta npm install. Configura OPENAI_API_KEY como variable de entorno en el terminal o en la configuración privada del proveedor de alojamiento. Opcional: OPENAI_MODEL. Ejecuta npm start y abre http://localhost:3000. No pegues la clave API dentro de index.html, no la compartas y no la subas a GitHub. El uso de la API puede generar cargos en la cuenta del proveedor. Publicar en un alojamiento con Node.js Sube estos archivos a un servicio que ejecute aplicaciones Node.js (por ejemplo, Render u otro proveedor equivalente), usa npm start como comando de inicio y configura OPENAI_API_KEY en la sección de variables secretas del servicio. El simulador y /api/ai deben servirse desde el mismo dominio para que la conexión funcione.
