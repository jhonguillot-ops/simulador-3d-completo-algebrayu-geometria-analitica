Cómo utilizar el simulador
  • Arrastra con un dedo para girar y observar la iglesia.
  • Usa dos dedos para acercar o alejar el modelo en el celular.
  • Usa los botones para cambiar de vista.
  • La distribución incluye altar, cruz, sillas, cocina y baño.
Nota: este modelo es una propuesta conceptual. Las dimensiones y la distribución deben verificarse con el plano real antes de construir.
